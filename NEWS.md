# jmpread 0.1.0

- Import JMP tables directly in R with read_jmp(), without Python or JMP.
- Support common numeric, fixed-width, variable-width, pooled and compressed
  column encodings, including missing values and Unicode text.
- Preserve temporal precision, column names, source metadata and raw row states.
- Select or exclude columns and return ordinary vectors with metadata = FALSE.
- Include a getting-started vignette and MIT-licensed example tables.
